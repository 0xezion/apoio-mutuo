# apoio-mutuo
Apoio mutuo aberta e sem muita burocracia, às vezes a cultura de segurança bloqueia a vontade de alguem ajudar e pedir ajuda, para solucionar essa demanda, o site é uma ideia para ajudar kompas encarcerados e fazer uma cmunicação mais eficiente entre quem pode ajudar e quem quer ser ajudado.
